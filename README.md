## Background

The meta-analytical database made available in this repository provides detailed data on cause-specific mortality of North American ungulates. Examples include publication details, species details, cause-specific mortality metrics, and predation metrics. We built this database using that of Hill et al. (2019a, 2019b) as an initial source. Modifications to Hill et al. (2019b)'s dataset include limiting species included to ungulates studied in North America, adding greater detail regarding predators and predation mortality, and adding studies published after 2018. For a complete description of modifications see the accompanying manuscript (Wehr et al. 2025).

This repository also includes R code associated with our analysis of the meta-analytical database. This annotated code uses generalized linear mixed models (GLMMs) as described in the accompanying manuscript (Wehr et al. 2025). Additionally, the figures resulting from these analyses are stored in this repository.

The contents of this repository may be freely used and modified, so long as the suggested citations above are appropriately referenced.
